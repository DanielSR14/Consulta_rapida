O problema

Todo dado de cliente exige abrir a Domínio.

Precisou do CNPJ de um cliente para emitir uma nota? Da inscrição estadual para um cadastro? Do endereço para um contrato? Hoje é abrir a Domínio, esperar carregar, localizar a empresa, navegar até a aba certa e copiar. Toda vez.

Ou caçar num PDF antigo, numa planilha solta na rede, num e-mail de dois anos atrás — e torcer para o dado estar certo.

Sem Consulta Rápida
  • Abrir a Domínio e fazer login
  • Localizar a empresa na lista
  • Abrir o cadastro, ir até a aba certa
  • Copiar o campo — um de cada vez
  • Deixar a Domínio aberta ocupando memória

30 a 60 segundos, e você saiu do que estava fazendo.

Com Consulta Rápida
  • Ctrl + Alt + D, de qualquer tela
  • Digitar “pad”
  • Enter para abrir os detalhes
  • Copiar cada campo com um clique

Cerca de 3 segundos, sem tirar os olhos da nota.

Como funciona

Três passos, uma vez só.

Instale o app

Um instalador, um clique. O Consulta Rápida fica quietinho na bandeja do Windows e sobe junto com o sistema, se você quiser.

Importe sua base — uma vez

Na Domínio: Relatórios → Cadastrais → Empresas, modelo Completo, exportar para Excel. Aponte o arquivo no app e pronto. A base vira um arquivo no seu PC. Repita só quando quiser atualizar.

Chame quando precisar

Aperte Ctrl + Alt + D em qualquer programa. Busque por nome, apelido, CNPJ, CPF, inscrição estadual ou cidade. Enter abre os detalhes; “Mais informações” mostra endereço completo, CNAE e registros.

Segurança

Seguro por construção.

O app foi feito para fazer uma coisa só — mostrar dados que já são seus — e nada além disso.

Nada sai do seu PC. A base fica num arquivo local. O app não tem servidor, não envia dados para lugar nenhum e não precisa de internet para funcionar.

Só leitura da Domínio. Você exporta um relatório; o app lê. Ele nunca escreve na Domínio nem em pastas da rede.

Sem rastreamento. Sem telemetria, sem anúncios, sem conta de usuário.

Por que o Windows mostra um aviso ao instalar?

Na primeira execução pode aparecer “O Windows protegeu o seu computador” (SmartScreen). Isso acontece com quase todo programa novo feito por um desenvolvedor independente que ainda não comprou um certificado de assinatura de código — que custa caro por ano, e este app é gratuito. Não é vírus, não é erro. Conforme mais gente instala, o aviso desaparece sozinho.
